# Contributing to SesMetin Pro

Thank you for your interest in contributing to **SesMetin Pro (Speech-To-Text)**!
Official Repository: https://github.com/The0Sanity/Speech-To-Text

## Code of Conduct
We are committed to providing a friendly, safe, and welcoming environment for all contributors. Please be respectful and constructive in all discussions.

## How to Contribute

### 1. Reporting Bugs
- Check the [Issues](https://github.com/The0Sanity/Speech-To-Text/issues) page to confirm the issue has not already been reported.
- Open a new issue using the **Bug Report** template.
- Include complete reproduction steps, operating system details, and relevant terminal/log output.

### 2. Suggesting Enhancements
- Open a new issue using the **Feature Request** template.
- Provide a clear problem statement and detailed proposed solution.

### 3. Submitting Pull Requests
1. Fork the repository and create a feature branch (`git checkout -b feature/my-feature`).
2. Follow standard Python PEP 8 conventions and maintain strict type annotations.
3. Adhere to the **Strict Zero-Emoji Policy**: Under no circumstances should emojis be included in code, docstrings, comments, commit messages, or documentation.
4. Maintain **Repository Attribution Integrity**: Always preserve the official repository URL: `https://github.com/The0Sanity/Speech-To-Text`.
5. Run the complete test suite before submitting:
   ```powershell
   python -m unittest discover tests
   ```
6. Submit your PR against the `main` branch.
